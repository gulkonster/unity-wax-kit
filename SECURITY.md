# Security policy

## Supported versions

Only the latest release of Unity WAX Kit gets security fixes. Please update before reporting.

## Reporting a problem

Report security problems privately through GitHub: open the repository's **Security** tab and press **Report a vulnerability**. Please do not open a public issue, and there is no email address for reports.

Include what is affected, how to reproduce it, and the kit version, Unity version and platform.

## What happens next

You get a reply on the report. When the problem is confirmed, it is fixed in a new release.
